# คู่มือการตั้งค่า Supabase แบบละเอียด (Supabase Setup Guide)

Supabase เป็นหนึ่งในผู้ให้บริการ Backend-as-a-Service ที่ยอดเยี่ยมมากและมีฐานข้อมูล PostgreSQL ให้ใช้ฟรีแบบจัดเต็ม นี่คือขั้นตอนการตั้งค่าเพื่อนำมาใช้กับโปรเจกต์ Next.js & Prisma ของเราครับ

## 🚀 เฟส 1: การสมัครและสร้างโปรเจกต์
1. เข้าเว็บไซต์ [supabase.com](https://supabase.com/) และทำการ Sign In (แนะนำให้ล็อกอินผ่าน GitHub)
2. เมื่อเข้ามาที่หน้า Dashboard ให้คลิกปุ่ม **"New Project"**
3. เลือก Organization (ถ้าเพิ่งสมัครจะมีอันเริ่มต้นให้เลือก)
4. กรอกรายละเอียดโปรเจกต์:
   - **Name:** ตั้งชื่อโปรเจกต์ (เช่น `dss-oltp-db`)
   - **Database Password:** สร้างรหัสผ่านที่เดายาก (เช่น `MySupabasePass123!`) **ข้อควรระวัง: ต้องจดรหัสผ่านนี้ไว้ให้ดี เพราะเดี๋ยวต้องใช้ต่อ**
   - **Region:** แนะนำให้เลือก `Singapore` (เพื่อให้เซิร์ฟเวอร์อยู่ใกล้ไทยมากที่สุด โหลดไวที่สุด)
5. กดปุ่ม **"Create new project"** (รอประมาณ 2-3 นาที เพื่อให้ระบบสร้างฐานข้อมูล)

---

## 🔗 เฟส 2: การดึง Connection String (DATABASE_URL)
หน้าตาเว็บของ Supabase มีการปรับปรุงใหม่บ่อยครั้ง วิธีที่ง่ายที่สุดในการดึงลิงก์ฐานข้อมูล ณ ปัจจุบันคือ:

1. ไปที่หน้า **Dashboard หลัก** ของโปรเจกต์คุณ
2. มองหาปุ่มคำว่า **"Connect"** (มักจะอยู่มุมขวาบนของหน้าจอ) แล้วคลิก
3. จะมีหน้าต่าง Pop-up เด้งขึ้นมา ให้เลือกแท็บ **"ORMs"** แล้วเลือก **"Prisma"** (หรือเลือกแท็บ URI ก็ได้)
4. คุณจะเห็นลิงก์หน้าตาประมาณนี้:
   `postgresql://postgres.xxxxxx:[YOUR-PASSWORD]@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres?pgbouncer=true`
5. ให้ Copy ลิงก์นี้มา และ **เปลี่ยนคำว่า `[YOUR-PASSWORD]` ให้เป็นรหัสผ่านจริงๆ ที่คุณตั้งไว้ในเฟส 1** (ลบวงเล็บก้ามปูออกด้วย)
   *ลิงก์ที่สมบูรณ์จะกลายเป็น `DATABASE_URL` ของคุณ*

*(หากหาปุ่ม Connect ไม่เจอ: ให้ไปที่รูปฟันเฟือง ⚙️ Project Settings -> เลื่อนหาหมวด **Configuration** -> เลือก **Database** -> เลื่อนลงมาหาหัวข้อ Connection string)*

## 🏗️ เฟส 3: การสร้างตารางข้อมูล (Tables)
เนื่องจาก Database ที่ได้มาใหม่ยังเป็น Database เปล่าๆ เราต้องสร้างตารางให้มันก่อน มี 2 วิธีให้เลือก:

### วิธีที่ 1: สร้างผ่านหน้าเว็บ Supabase โดยตรง (SQL Editor)
1. กดเมนู **SQL Editor** (สัญลักษณ์ `</>`) ที่แถบเมนูด้านซ้าย
2. กดปุ่ม **New query**
3. คัดลอกคำสั่ง `CREATE TABLE` ทั้งหมดของคุณ (Customers, Products, Orders, Order_Items) ไปวางในช่องพิมพ์โค้ด
4. กดปุ่ม **Run** เพื่อสร้างตาราง

### วิธีที่ 2: ใช้ Prisma สร้างให้อัตโนมัติ (แนะนำ)
หากคุณมีไฟล์ `schema.prisma` อยู่แล้ว คุณสามารถเปิด Terminal ในโปรเจกต์ (ที่เครื่องตัวเอง) แล้วสั่ง:
```bash
npx prisma db push
```
Prisma จะวิ่งไปที่ Supabase และสร้างตารางทั้งหมดให้อัตโนมัติตามโค้ดในไฟล์ Prisma ทันที

## ☁️ เฟส 4: การนำไปใช้งานกับ Next.js & Vercel

**1. สำหรับรันทดสอบในเครื่องตัวเอง (Local):**
- เปิดไฟล์ `.env` ในโปรเจกต์
- ใส่ค่าลิงก์เข้าไป: `DATABASE_URL="postgresql://postgres.xxxxxx:รหัสผ่าน@aws-0.../postgres"`

**2. สำหรับการนำขึ้น Vercel:**
- เข้าไปที่ Dashboard โปรเจกต์บนเว็บไซต์ Vercel
- ไปที่ **Settings** -> **Environment Variables**
- ช่อง Key ใส่ `DATABASE_URL`
- ช่อง Value ใส่ ลิงก์ที่สมบูรณ์ (ตัวเดียวกับที่ใส่ใน .env)
- กด **Save** แล้วไปสั่ง Redeploy โปรเจกต์ในหน้า Deployments ได้เลยครับ!
